# Phill

Telegram-бот (Python 3.11+, aiogram 3).

## Запуск

- Установить `pip install -r requirements.txt`.
- Задать `TELEGRAM_TOKEN`, `ADMIN_ID`, `DARKAPI_KEY` (или `API_KEY` / `GROQ_API_KEY`). Секреты не хранить в Git.
- Для собственного endpoint: `AI_BASE_URL` вместе с `API_KEY`.
- `AI_MODEL` — точный ID модели у провайдера; `AI_ANALYZER_MODEL` — необязательный ID для анализа. Если `/models` недоступен, требуется `AI_MODEL`.
- Запустить **один** процесс `python bot.py`. На хостинге оставить одну реплику, не запускать одновременно web service и background worker с одним токеном.

## Telegram 409 Conflict

Смена токена не устраняет два процесса, если оба получили новый токен. Проверить старые сервисы, worker, локальные запуски и реплики. Остановить дубликаты, затем запустить один сервис. Бот снимает webhook при старте без удаления накопленных обновлений.

Локальная блокировка предотвращает второй запуск с тем же токеном на одной машине. Между разными контейнерами она не действует: при получении 409 бот завершает polling с явной ошибкой. Автоперезапуски хостинга нужно отключить/остановить для лишнего сервиса.

## AI и задержки

SDK не делает скрытых повторов. Основной ответ имеет общий бюджет ожидания API 22 секунды, максимум три модели из каталога провайдера, до 10 секунд на запрос. Ошибка неподдерживаемого penalty допускает один повтор без этого параметра в том же бюджете. Неподдерживаемые модели пропускаются до следующего успешного обновления каталога/перезапуска. При 401/402/403/429 цепочка запросов прекращается: проверить ключ, баланс и лимиты. При полном сбое ответ не отправляется, ошибка учитывается в `/status`.

Скачивание медиа, поиск новостей, Telegram и имитация набора идут отдельно от этого бюджета. Промпты и характер Фила не изменены.

Ранее встроенный ключ DarkAPI удалён. Если он использовался, отозвать его у провайдера и задать новый через `DARKAPI_KEY` — старый остаётся в истории Git.
